# Quiz Web Application

A responsive quiz web application built using HTML, CSS, and JavaScript. The application presents multiple-choice questions, tracks the user's score in real time, and maintains a high-score leaderboard using the browser's Local Storage.

Quiz questions are loaded dynamically using the Open Trivia Database API, providing an interactive quiz experience.

## Features

- Interactive multiple-choice quiz
- Dynamic question loading using an API
- Real-time score tracking
- High-score leaderboard
- Local Storage integration
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Open Trivia Database API
- Browser Local Storage

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Click **Play** to start the quiz.
4. Complete the quiz and save your score.
5. View the leaderboard.
